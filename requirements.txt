# 🏫 Школьный Telegram-бот

Бот для управления домашними заданиями, расписанием и рассылкой для школьного класса.

---

## 📋 Возможности

### Для учеников:
- 📚 Просмотр домашнего задания по всем предметам
- 📅 Просмотр актуального расписания
- 🔔 Подписка/отписка от рассылки

### Для администратора (учителя):
- ✏️ Добавление ДЗ с текстом, фото или файлом
- 🗑 Удаление ДЗ по предмету
- 🧹 Очистка всего ДЗ сразу
- 📤 Загрузка расписания (фото или документ)
- 📨 Рассылка сообщений всем подписчикам
- 👥 Просмотр статистики подписчиков

### Поддерживаемые предметы:
- Алгебра, Биология, ВиС, География, Геометрия
- Английский язык (группа 1), Английский язык (группа 2)
- Информатика, История, Литература
- Обществознание, Русский язык, Физика, Химия

## 🚀 Установка и запуск

### 1. Создай бота в Telegram
1. Напиши [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot` и следуй инструкциям
3. Скопируй полученный **токен**

### 2. Узнай свой Telegram ID
- Напиши боту [@userinfobot](https://t.me/userinfobot)
- Он покажет твой числовой ID

### 3. Настрой `config.py`
Открой файл `config.py` и замени:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"  # ← вставь токен от BotFather

ADMIN_IDS = [
    123456789,  # ← вставь свой Telegram ID
]
```

### 4. Установи зависимости
```bash
pip install -r requirements.txt
```

### 5. Запусти бота
```bash
python bot.py
```

```
└── database.json       # БД (создаётся автоматически при запуске)
```

## 💡 Советы по использованию

**Добавление ДЗ:**
1. Нажми "⚙️ Панель администратора" → "✏️ Добавить ДЗ"
2. Выбери предмет
3. Напиши текст задания (или `/skip` если только файл)
4. Прикрепи фото/документ (или напиши `/done` без файла)

**Загрузка расписания:**
1. Нажми "📤 Загрузить расписание"
2. Отправь фото или PDF-файл с расписанием
3. При желании добавь подпись к файлу

**Рассылка:**
1. Нажми "📨 Рассылка"
2. Отправь сообщение (текст, фото или документ)
3. Подтверди отправку, написав "да"

## ⚙️ Запуск как сервис (Linux)

Чтобы бот работал постоянно, создай systemd-сервис:

```ini
# /etc/systemd/system/schoolbot.service
[Unit]
Description=School Telegram Bot
After=network.target

[Service]
User=your_user
WorkingDirectory=/path/to/school_bot
ExecStart=/usr/bin/python3 /path/to/school_bot/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable schoolbot
sudo systemctl start schoolbot
```
